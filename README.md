# LibraryOS - React Book Management System

A modern, responsive Book Management System built with React and Vite. This application allows users to perform full CRUD operations on a book database, featuring a custom debounced search, dynamic data visualization, and an optimistic UI.

## ✨ Features
- **Full CRUD Operations:** Seamlessly add, edit, view, and delete books.
- **Enterprise-Grade Table:** Sortable columns and animated row transitions.
- **Data Visualization Dashboard:** Dynamic pie and bar charts built with Recharts, utilizing algorithmic color generation.
- **Optimistic UI Deletions:** Instant UI updates with background API syncing and rollback capabilities.
- **Performance Optimized:** Custom 300ms debounce hook for search to minimize API calls.
- **Modern UI/UX:** Glassmorphism design elements, framer-motion animations, and responsive layout.

## 🛠️ Tech Stack
- **Frontend Framework:** React (Vite)
- **API Handling:** Axios
- **Form Management & Validation:** React Hook Form
- **Animations:** Framer Motion
- **Icons:** Lucide React
- **Data Visualization:** Recharts
- **Data Source:** MockAPI.io
